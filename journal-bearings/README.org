#+title: Journal bearings
#+startup: content
#+options: toc:2 num:nil

Julia geometry, surface meshes and reduced lubrication models for cylindrical
and conical journal bearings. The shared =mesh/2d/= mesher builds periodic
quadrilateral housing surfaces, unported or fitted around a circular +Y inlet.
Zero semi-cone angle gives a cylinder.

The shared full-film and pressure-only Swift–Stieber solvers accept supplied
unported cylindrical or conical tensor meshes, with uniform or adjusted spacing.
JFO cavitation and rigid load-balance interfaces use uniform grids. These solvers do not consume fitted
meshes or implement thermal flow or elasticity. The named simulation CLI
supports *unported cylinders only*. Gmsh volume-mesh experiments live in =expts/=;
they are separate from the surface mesher and Reynolds solvers.

* Setup and documentation

Run commands from =journal-bearings/=:

#+begin_src sh
julia --project=. -e 'using Pkg; Pkg.instantiate()'
#+end_src

- [[file:mesh/2d/README.md][Surface meshing]]: API, units, acceptance and examples.
- [[file:simulation/README.md][Simulation]]: solver interfaces and numerical verification.
- [[file:simulation/reynolds/README.md][Reynolds models]]: equations, checks and commands.
- [[file:docs/solver-support.md][Solver support]]: mesh compatibility and known integration limits.

Numerical verification is not experimental validation. Signed negative pressure
is not cavitation; the Gangrade pressure comparison is not fully matched.

* Named cylindrical case

#+begin_src sh
julia --project=. mesh/2d/generate.jl \
  --experiment demo-cylinder --geometry unported \
  --journal-radius-mm 50 --length-mm 100 --clearance-mm 0.05 \
  --cone-angle-deg 0 --eccentricity-ratio 0.6 \
  --n-theta 128 --n-axial 64
julia --project=. simulation/reynolds/run.jl \
  --experiment demo-cylinder --run vg32-2000rpm \
  --rpm 2000 --viscosity-pa-s 0.02752 --sweep
#+end_src

Geometry lengths are mm; dynamic viscosity is Pa·s. These are illustrative
inputs, not a measured operating point.

The mesh command creates =out/cases/demo-cylinder/{mesh.vtk,experiment.toml}=.
The simulation writes =runs/vg32-2000rpm/= beneath that case, containing
=run.toml=, =full-film.vtk=, =diagnostics.toml= and =convergence.tsv=.
The mesh checksum is verified on every simulation invocation.

To rerun identical saved inputs, use =--experiment demo-cylinder --run
vg32-2000rpm --replace=; add =--sweep= to regenerate the sweep. Different
operating inputs require a different run name; different geometry or counts
require a different experiment name.

* Standalone fitted surface

#+begin_src sh
julia --project=. mesh/2d/generate.jl \
  --geometry surface-feed --journal-radius-mm 50 --length-mm 100 \
  --clearance-mm 0.05 --cone-angle-deg 10 --eccentricity-ratio 0.6 \
  --n-theta 128 --n-axial 64 --feed-diameter-mm 5 --feed-z-mm 50 \
  --output out/inlet.vtk
#+end_src

The output path must be fresh. Fitted exports contain land quads and explicit
rim edges, not a =feed_cells= mask or a 3D passage. Counts size the background;
the final cell count differs. Unsupported transitions or failed quality/stability
checks reject the request. The 5 mm diameter is a project example, not a
reported Gangrade dimension.

=--output= and =--experiment= are mutually exclusive. Named fitted cases are
unsupported. Both CLIs provide =--help= / =-h= and accept =--name VALUE= or
=--name=VALUE=.
