#+title: Journal bearings
#+startup: content
#+options: toc:2 num:nil

Hydrodynamic lubrication models for cylindrical and conical journal bearings.
Journal rotation drives lubricant through a clearance that narrows and widens
around the circumference, producing pressure that can support a load.

This project builds numerical models of that film, beginning with geometry and
meshing before moving to reduced lubrication models and full three-dimensional
CFD. Current grid work focuses on conical bearings; a zero semi-cone angle
gives the corresponding cylindrical geometry.

* Approach

I use Julia for geometry, direct surface grids, and reduced numerical models.
Gmsh supports the three-dimensional mesh experiments. OpenFOAM handles full
three-dimensional flow models.

The main questions are how clearance, eccentricity, speed, load, lubricant, and
bearing shape affect pressure, load capacity, cavitation, heat transfer, and
stability. Reduced and three-dimensional models use common geometry and
operating conditions so their predictions can be compared with each other and
with published experimental and numerical results.

* Generate a 2D conical housing grid

From =journal-bearings/=, run (all lengths in mm):

#+begin_src sh
julia --project=. mesh/2d/conical/generate.jl \
  --geometry unported --journal-radius-mm 50 --length-mm 100 \
  --clearance-mm 0.05 --cone-angle-deg 10 --eccentricity-ratio 0.6 \
  --n-theta 512 --n-axial 256 --output out/my-unported.vtk
#+end_src

Use =--geometry surface-feed= with =--feed-diameter-mm 5 --feed-z-mm 50= to
label a central feed footprint; choose a distinct output filename. The 5 mm
opening is a project example, not a documented Gangrade dimension. The optional
resolution defaults to 512 by 256. Use =--help= or =-h= for the manpage-style
option list; long options accept either =--name VALUE= or =--name=VALUE=.
Output paths must not already exist. This writes a Quad4 surface VTK with
cell-centre radial gaps, not a 3D fluid mesh or a pressure solution. Feed cells
are a mask, not a resolved passage or prescribed supply condition. Run
=julia --project=. mesh/2d/conical/generate_checks.jl= for CLI checks.
