# Repository instructions

- Start by reading `.tasks/PROJECT.org` and checking live Git state.
- Use `docs/ENGINEERING.md` as the engineering standard. Always read **Aim**
  and **Prepare a code change**. Read only task-relevant sections after that:
  code boundaries, tests, documentation, prose, or numerical software.
- Before handoff, follow **Review a change** and report only checks run.
- Work one reviewed checkpoint at a time. Do not create future scaffolding.
- Preserve unrelated user changes and ignored task state.
